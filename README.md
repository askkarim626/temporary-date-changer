# Temporary Date Changer

Python/Tkinter desktop application for temporarily changing the system date and time.

## Usage

Run `Date_Changer.py` with administrator privileges. When restoring the clock, the application adds the elapsed real time so the system time does not become delayed.

The Windows executable is available at `dist/Date_Changer.exe`.

## Requirements

- Python 3.11+
- Tkinter
- Administrator privileges
